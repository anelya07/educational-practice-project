## Project Description

This project predicts median house prices in California using the California Housing dataset (1990 census data, 20,640 records). We applied machine learning techniques including data preprocessing, feature engineering, and two regression models — Linear Regression and Random Forest — to predict housing prices based on location, income, and housing characteristics.
